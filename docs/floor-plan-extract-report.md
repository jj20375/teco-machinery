# 樓層分區抽取報告

由 `npm run extract:floor-plan` 產生。分區範圍是設計端在 CAD 圖上畫的紅框，不是程式推測的。
面積換算僅供判讀分區大小，**不是施工尺寸**。

## B1

- 底圖來源：`assets/cad/CLUB-M-B1.svg`（精簡版，沒有紅框）
- 分區來源：`assets/cad/CLUB-M-B1-zones.svg`（`class="st32"` 的紅框）
- 圖面尺寸：712.3 x 543.3 圖面單位；底圖實際範圍 21, 11.8, 690.3, 527.8
- 比例尺：1 ㎡ ≈ 79.16 圖面單位²（相對 B1 圖面 1 倍）；**非施工尺寸**
- 圖面方向：來源檔旋轉 180°（對齊現場最終版 PPT）
- 編號方式：依旋轉後的圖面位置自動給（由上而下、由左而右）
- 補畫的分區：3 個（PPT 有送風機但設計端沒畫紅框：B5、V區女廁、V區男廁）
- 1F 小圖：有（分區 1F 大門、1F 電梯前，外框另列在 EXTRA_OUTLINES）
- 分區數：77（已命名 2 個，其餘顯示編號）
- 總面積：2075.7 ㎡
- 過濾條件：面積小於 4 ㎡、或短邊小於 12 單位的紅框不列入，共濾掉 6 個
- 建築外框：12 個角點
- 底圖輸出：`public/floor-plans/b1-base.svg`（838 KB）
- 警告：無
