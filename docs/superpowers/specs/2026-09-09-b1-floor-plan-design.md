# B1 簡化空間與設備配置

使用者已確認：依 B1-空調位置.pdf 保留外框、主要分區、走道與中央空間，移除施工線、家具及原有設備符號。2D SVG 是主要配置介面，Three.js 提供簡單立體瀏覽，兩者共用座標。

- 手動整理區域輪廓，保留原圖相對位置；無法辨識的名稱以圖面位置命名，不宣稱用途或真實尺寸。原圖灰區與中央空間標為待確認，禁止放置設備。
- 後台新增「空間設備配置」，選擇現有冰水主機或 B1 FCU，點選區域放置、拖曳或用方向鍵移動、旋轉、移除位置。設備台帳本身不受影響。
- 使用者追加確認：先點選區域，再加入冰水主機或 FCU。正常設備為藍色，異常／待保養為紅色，離線／停止為灰色。即使冰水主機在運轉，超過既有告警門檻仍須呈現紅色。
- 區域熱力效果：含有正常運轉設備的已配置區域顯示藍色光暈；含有異常或待保養設備的區域一律以紅色光暈優先。離線／停止設備不製造光暈。紅光會依可用量測溫度提高亮度，但冰水主機的出水溫度不是室溫，仍以告警狀態決定紅光。2D SVG 與 Three.js 3D 共用同一規則。
- 不預先假定任何設備位置。點位以設備 ID 綁定，區域與位置獨立儲存。未配置設備不出現在圖面。
- SVG 使用固定 viewBox，座標經畫面轉換後更新；放置與移動都須驗證區域，禁止落於圖外、待確認區域或其他設備標記。
- 儲存至同一瀏覽器的 localStorage，明示本機範圍與模擬設備資料。手動儲存、離頁提醒、讀寫失敗提示；驗證格式、數字、重複設備和區域，不默默覆寫損壞資料。
- 前台 B1 與後台 B1 總覽共用已儲存配置；B2 顯示尚未提供配置圖，不複用 B1。移除原先與真實空間無關的模擬熱點。
- 3D 僅顯示簡單區域量體及設備方塊，可旋轉/縮放，配置仍在 2D 操作；失去 WebGL 時提供切回 2D。
- 驗證：一個可執行的座標/資料測試，加上型別檢查、正式建置、瀏覽器放置/移動/儲存/重載/3D/樓層切換檢查。
